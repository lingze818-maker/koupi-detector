# 共识口癖扩词

项目：koupi-detector（口癖检测器）。语义层现状就是这份词表和 `tics/default.json`，没有单独的 `semantic/` 目录。

两人同判 tic 的 32 条只用来对照 span。词条写在 `tics/default.json` 的正则里。`lib/lexicon.mjs` 没改，那些词只服务句式槽位，不扫全文。金标句子没有改。

扩写前，这 32 条命中 **2/32**（s046「语调平缓」、s048「听不出半分波澜」，都是原有规则）。扩写后命中 **31/32**。情绪抹平 18/18，比喻套话 13/14。新规则多打中 29 条。没打中的是 s127「好似在讲丢了把伞」。

## 新增词条

| 规则 | 盖住的说法 |
| --- | --- |
| `emo.voice-level` | 声线 / 嗓音 / 话声 / 嗓子 / 调门后面的四平八稳、稳稳当当、一点高低都没有、找不到一个弯、一直是平的、没有起落 |
| `emo.no-wave` | 声音或语气里没起波澜；语气里连个涟漪都没有。要有声音、语气、心里、眼底这类锚点 |
| `emo.still-well` | 「他/她/我古井无波」或「古井无波似的 / 地」 |
| `emo.eye-flat` | 眼底或眼中静得没有一点起伏 |
| `emo.said-bland` | 话说得极淡 |
| `emo.face-still` | 五官纹丝不动 |
| `emo.unrushed-air` | 不急不缓的劲儿 |
| `emo.emotion-tidied` | 情绪收得干干净净 |
| `emo.no-feeling` | 不带感情的声音、毫无起伏的嗓音、一点情绪也挂不上 |
| `met.minutes` | 像在宣读会议纪要。要有「像 / 仿佛 / 好像 / 好似」 |
| `met.manual` | 像在读说明书 |
| `met.progress` | 仿佛在汇报工作进度 |
| `met.commonplace` | 像家常便饭一样、自然得不能更自然、就像讲每天都会发生的事 |
| `met.trivial` | 芝麻绿豆的小事 |
| `met.obvious` | 像在说一加一等于二、像是在讲太阳从东边出来 |
| `met.small-talk` | 跟聊家常差不多、像随口点评 |
| `met.sealed` | 盖了章的结论、没得商量的定论 |

## 刻意没加

- s127「好似在讲丢了把伞」。伞是这一句里的具体物件，不是可复用套话。收成正则会把真在讲丢伞的句子打成口癖。
- 不带「像 / 仿佛」的字面动作：吃家常便饭、灯下读说明书、坐下聊家常、秘书在宣读会议纪要、会上汇报进度、黑板上的一加一等于二。
- 没有声音、语气或眼底锚点的：湖面没起波澜、湖面连个涟漪都没有、山路没有一点起伏、地势毫无起伏、做事四平八稳、纹丝不动地站住、不急不缓地走上石阶。
- 「古井无波，倒映着星子」这种写井水的句子。只收人称紧挨着的「古井无波」，或后面带「似的 / 地」。
- 声音很稳、仪器平稳、湖面平静、元话语「念平一点」。不在这 32 条 span 里，而且会误伤具体动作或字面用法。
- 「干巴巴」。共识条的 span 是「一点情绪也挂不上」，干巴巴也能形容实物。
