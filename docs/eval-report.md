## 要量的东西

人说话省力。杯子里是白水，就说「这是杯白水」。模型常写成「这不是茶，也不是酒，而是白开水」：先排除没人问过的选项，再落到真正要说的那半句。节奏是固定的，信息只在最后。

检测回答三件事。

1. 金标口癖里，系统在作出判定的那些条上抓住了多少（检出率）。
2. 金标非口癖里，系统在作出判定的那些条上误伤了多少（误报率）。
3. 人工可判定的条目里，系统自己放弃判定的比例（不可判定率）。

冗余比回答第四件：被判成口癖的句式，比只留断言的最短改写长多少。

## 口径

系统对每条金标给出 `positive`（口癖）、`negative`（非口癖）或 `indeterminate`（不可判定）。人工标了 `unjudgeable` 的条目不进下面任何比率。

- 检出率 = 判成口癖的金标口癖 / 系统作出了判定的金标口癖。
- 误报率 = 被判成口癖的金标非口癖 / 系统作出了判定的金标非口癖。
- 不可判定率 = 系统不可判定 / 人工可判定的金标。

弃权不进检出率和误报率的分子、分母，也不算一次成功检出。

按类别拆开时，分母不一样，需要分开看：

- 某类的检出率、不可判定率，只在「金标口癖且类别就是这一类」的条目上算。
- 某类的误报率，分母仍是全部已经作出判定的金标非口癖；分子是其中被这一类判成口癖的条数。

所以总检出率会把情绪抹平、比喻套话算进去，句式模板那一行只看句式。两份数据用同一口径。

## 冗余比怎么算

不调用模型。每条句式命中按形状收成最短改写，只留断言：

| 句式 | 最短改写 |
| --- | --- |
| 不是 A，也不是 B，而是 C | 是 C |
| 没有 A，也没有 B，只是 C | 只是 C |
| 没有 A，只是 B | 只是 B |
| 不是 A，而是 B；没有 A，而是 B | 是 B |
| 没有 A，也没有 B | 删去。没有断言可留 |
| 像在 A，又像是在 B | 像是在 B |

字数去掉空白、保留标点，和密度用同一口径。

- 冗余比 = 命中字数 / 最短改写字数。
- 冗余字 = 命中字数 − 最短改写字数。
- 每千字冗余字 = 冗余字合计 / 文本字数 × 1000。

没有断言可留时，冗余比留空，不进均值和最大值，命中字数全部算进冗余字。只把判定为口癖的句式算进去。前文提过的真实纠正会放行，不进这三项。系统标成不可判定的也不进。跨句命中的原文字数把句号、问号、叹号、省略号和换行算进去，最短改写仍然只留断言。同一句「没有糖，也没有牛奶，只是白水」，前文没人提过糖和牛奶时计入；前文问过糖和牛奶时放行。

句子级金标的分母很短，每千字会被抬高。拿去扫一整段对话时，分母是整段角色文本。单条转折绕不绕，看冗余比本身：断言越长，比值越接近 1。

弃权是故意的。槽位一虚一实、前文只出现了部分选项、单句又没有前文、或者短排比看不出套话时，规则不猜。这些条不把检出率抬高，也不把误报率抬高。

## 已知局限

1. 同一轮里，不是/没有和而是/只是之间，紧挨着或只隔一个句界（。！？…，以及换行）时照常判定。两段式再隔一个无关整句：前文已经把被否定项都说过，就放行；否则标不可判定，不判成口癖。再多隔一句就不接。三段式本身可以跨两个句界。不跨说话人轮次：上一轮的「不是责备。」接不上这一轮的「而是把话放平。」
2. 前文对照仍是子串，不是指代消解。介词开头的槽会先剥一层介词，被、给、跟、对、为后面若还拖着动词，再拿前两字去对。从前、对方、被单、为什么、从容这些不是「介词 + 名词」的说法不剥。前文说「那种饮料」、后文否定「茶」，仍然对不上。
3. 回看默认 4 轮。更早提过的选项，会被当成没提过。
4. 冗余比只看结构，不判断改写后好不好读，也不调用模型。「没有 A，也没有 B」没有断言可留，比例留空，字数全部算冗余。「像在 A，又像是在 B」只留后一侧，这是约定。
5. 情绪抹平和比喻套话的正例大多贴着现有词面。换一种近义说法，规则可以完全看不见。留出集 v2 里这类句子的漏检，就是这个限度。
6. 旧留出集的修复后分数不是完全干净的估计。留出集 v2 只跑了一次，但两份数据都是虚构句子，作者写的时候看得到规则，不能代替真实对话。
